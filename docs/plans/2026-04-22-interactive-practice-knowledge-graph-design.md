# 交互式实践知识图谱画布设计

**日期**: 2026-04-22  
**范围**: 在现有“通用实践知识图谱 MVP”基础上，把阅读层从关系板改造成真正的交互式图谱画布。  
**非目标**: 不做 community 聚类、minimap、insights、单 HTML 自包含离线封装。

---

## 1. 背景

当前实现已经具备：

- 结构化 Markdown 作为唯一事实源
- 图谱生成脚本
- 项目视角切换与分数计算
- 搜索、筛选、详情展示

但主阅读入口仍是列表式关系板，不具备交互式知识图谱应有的空间关系感和节点操作体验。用户明确希望它更接近外部参考实现的“交互式知识图谱画布”，而不是卡片化排列。

---

## 2. 目标

本轮改造只实现最小必要的交互式图谱能力：

- SVG 画布上的节点与边
- 力导布局
- 缩放、拖拽、平移
- 搜索高亮与聚焦
- 节点点击后的详情抽屉
- 邻居高亮与非相关节点降噪
- 项目视角切换后推荐方案和分数即时刷新

---

## 3. 保持不变的部分

### 3.1 事实源

`knowledge/**/*.md` 仍然是唯一事实源。

### 3.2 评分模型

评分公式仍然是：

```text
final_score = base_score + project_adjustment
```

### 3.3 默认阅读策略

首屏仍然只展示：

- 所有 `Practice`
- 每个 `Practice` 在当前视角下的推荐 `Option`

这样可以避免交互式图谱一上来就变成难读的毛线球。

---

## 4. 页面结构

页面改成三段结构：

### 4.1 顶栏

包含：

- 项目视角切换
- 搜索框
- 类型 / 场景 / 约束筛选
- 重置视图按钮

### 4.2 主画布

中间区域为 SVG 图谱画布，负责：

- 节点和边的空间布局
- 拖拽节点
- 平移和缩放
- 高亮当前节点及其邻居

### 4.3 右侧详情抽屉

点击节点后打开，显示：

- 节点基本信息
- 评分信息
- 关联 Practice / Option / Rule / Constraint / Context
- Markdown 正文分节内容
- 原始文档路径

---

## 5. 交互流

### 5.1 初始进入

只渲染 `Practice + 推荐 Option` 的主关系。

### 5.2 搜索

- 对命中节点高亮
- 如果命中数量较少，自动聚焦到相关节点区域
- 不破坏当前节点选择状态

### 5.3 点击节点

- 设置当前选中节点
- 抽屉刷新为该节点详情
- 一阶邻居节点与相关边高亮
- 其余节点降噪

### 5.4 切换项目视角

- 不重新读取 Markdown
- 直接基于已有数据刷新当前推荐 Option
- 更新 Option 的 `current_score`
- 如果当前选中的是 Practice，则同步更新候选排序

### 5.5 筛选

筛选控制“当前可见节点集合”，不改底层知识数据。

---

## 6. 数据结构调整

在保持当前 `graph-data.json` 主结构不变的前提下，增加前端友好字段。

### 6.1 节点字段

每个节点增加或补齐：

- `label`
- `node_group`
- `neighbor_ids`
- `current_score`

其中：

- `Practice` 节点的 `current_score` 可为空
- `Option` 节点的 `current_score` 由当前项目视角决定

### 6.2 Practice 衍生字段

保留：

- `recommended_options`

增加：

- `ranked_option_ids`

用于在详情抽屉中展示候选排序，减少前端重复排序成本。

### 6.3 边字段

保留：

- `from`
- `to`
- `type`

增加：

- `edge_group`
- `strength`

其中：

- `has_option` 作为主关系
- 其他关系作为辅助关系

---

## 7. 视觉策略

视觉仍保持当前项目已有的暖色纸面感，但主变化在“图谱空间表达”而不是“卡片排版”。

节点层级：

- `Practice`：视觉最强，尺寸最大
- 推荐 `Option`：次强
- 其他节点：弱化

边层级：

- `Practice -> 推荐 Option`：主边
- 辅助关系边：更轻、更淡

高亮策略：

- 当前节点：最强
- 邻居节点：次强
- 非相关节点：降低透明度

---

## 8. 错误处理与降级

- `graph-data.json` 读取失败时，页面展示明确错误提示
- 节点字段缺失时，前端降级显示最小信息，不允许整页崩溃
- 某个 `Practice` 没有推荐 `Option` 时，仍显示 Practice 节点
- 搜索无结果时，提示“无匹配节点”，但不重置整个图谱状态

---

## 9. 测试策略

### 9.1 保留现有 Node 原生测试

继续覆盖：

- frontmatter 解析
- 节点构建
- 边构建
- `final_score` 计算

### 9.2 新增前端纯函数测试

覆盖：

- 当前视角下推荐 Option 选择
- 邻居集合构建
- 搜索匹配与节点过滤

### 9.3 浏览器烟测

验证：

- 画布加载
- 节点点击
- 详情抽屉
- 项目视角切换
- 搜索高亮

---

## 10. 最终结论

这次改造不是重做知识系统，而是把主阅读入口从“关系板”升级成“真正的交互式知识图谱画布”。

保留：

- Markdown 事实源
- 评分模型
- 项目视角
- 自包含目录结构

替换：

- 主阅读界面的表达方式

这样可以在不扩展到高级图谱功能的前提下，把用户体验拉到符合“交互式知识图谱”的最低可用水平。
