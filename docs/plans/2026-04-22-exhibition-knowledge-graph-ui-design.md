# 展示型信息画布 UI 重构设计

**日期**: 2026-04-22  
**范围**: 重构交互式知识图谱的阅读层 UI，使其从“后台关系板”转为“展示型信息画布”。  
**非目标**: 不修改 Markdown 事实源、不调整评分公式、不新增图谱能力边界。

---

## 1. 背景

当前图谱已具备交互式画布、节点拖拽、缩放、平移、搜索、项目视角切换和详情抽屉，但阅读层依然明显保留了“数据后台”痕迹：

- 顶部控制区像一整块表单面板，主次不分
- 节点类型在筛选区、画布和抽屉里的视觉语法不一致
- 详情抽屉把标签、分数、关系和正文堆成同一层级，阅读节奏混乱

用户明确要求把整体气质调整为“展示型信息画布”，同时保持平衡型信息密度，既能阅读，又不失工具性。

---

## 2. 目标

本轮 UI 重构要实现三件事：

- 建立稳定的节点类型视觉语法
- 把详情抽屉重构成“展陈区 + 结构区”
- 把顶部区域压缩成轻量控制带，让主画布成为视觉中心

---

## 3. 总体视觉方向

整体风格从“暖色玻璃后台”调整为“策展式阅读画布”：

- 背景更克制，主对比度更集中在节点和详情抽屉
- 控制区退后，画布前置
- 选中节点和推荐方案成为第一视觉焦点
- 右侧抽屉更像作品说明牌，而不是数据块堆叠

信息层级收敛为三层：

1. 当前选中节点
2. 直接关联节点与核心说明
3. 次要过滤项与补充正文

---

## 4. 顶部工具带

顶部区域重构为两层：

- 第一层：品牌标题、当前阅读定位、主操作
- 第二层：次级筛选

具体策略：

- `项目视角` 与 `搜索` 作为第一优先级控件
- `适用场景 / 约束条件 / 节点类型` 作为次级筛选
- `节点类型` 使用紧凑的 segmented chips，不再使用大面积复选块
- `重置` 改为次要动作按钮，不再占据独立空白区域

---

## 5. 节点类型视觉语法

### 5.1 Practice

- 作为主节点，使用最大号横向卡片
- 显示类型眉标、标题、简短元信息
- 视觉上像“主题展签”

### 5.2 Option

- 同样使用卡片，但比 Practice 更轻更窄
- 推荐项使用更强描边与局部实色头部
- 非推荐项退为低饱和描边卡片

### 5.3 Context / Constraint / Rule

- 统一改为“徽章型节点”
- 不再和 Practice / Option 竞争同等级卡片视觉
- 通过颜色和边框细节区分：
  - `Context`：信息蓝
  - `Constraint`：风险红
  - `Rule`：制度金 / 深墨

### 5.4 ProjectProfile

- 作为视角印章出现
- 只在相关筛选或节点关系中出现，不抢主视觉中心

### 5.5 连线

- 主关系线明确
- 辅助关系线更轻更淡
- 当前节点的一阶关系线强化，其余明显退后

---

## 6. 详情抽屉

详情抽屉改成固定的两段式结构。

### 6.1 上半部：展陈区

回答“它是什么”：

- 类型
- 状态
- 标题
- 摘要
- 当前推荐状态或当前视角推荐结果

这部分要优先建立节点认知，不让分数和关系打断第一阅读路径。

### 6.2 下半部：结构区

回答“为什么推荐”和“它和谁有关”：

- 评分
- 关系
- 正文
- 原始文档

其中：

- `final_score` 作为主指标单独突出
- `base_score` 和 `project_adjustment` 退为辅助解释
- 关系按类别分组，而不是一堆混杂标签
- 正文排版回到侧栏可读性优先

---

## 7. 保持不变的部分

- `knowledge/**/*.md` 仍是唯一事实源
- 评分公式仍为 `base_score + project_adjustment = final_score`
- 图谱交互能力边界不扩展
- 默认首屏仍是 `Practice + 当前视角推荐 Option`

---

## 8. 实现边界

本轮仅修改阅读层文件：

- `knowledge/graph/knowledge-graph.html`
- `knowledge/graph/knowledge-graph.css`
- `knowledge/graph/knowledge-graph.js`

必要时补充最小 UI 结构测试，但不改数据生成主逻辑。

---

## 9. 验证方式

- Node 原生测试验证页面骨架和最小结构契约
- 浏览器烟测验证：
  - 节点类型表现
  - 详情抽屉层级
  - 顶部工具带收敛后仍可操作
  - 既有交互能力不回退

---

## 10. 结论

这次不是“换一套颜色”，而是把图谱阅读层重新组织成一套稳定的展示型信息画布：

- 工具带退后
- 画布前置
- 节点类型可一眼识别
- 抽屉先讲节点身份，再讲评分和关系

这样才符合知识图谱作为主阅读入口的定位。
